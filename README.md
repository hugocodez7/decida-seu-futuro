# 🎓 Decida Seu Futuro

Um guia interativo de linha de comandos (CLI) desenvolvido em Python para ajudar estudantes e curiosos a descobrirem a área de estudo e o curso superior que melhor combinam com o seu perfil.

## 📖 Sobre o Projeto

O **Decida Seu Futuro** funciona como um teste vocacional rápido. Através de uma série de perguntas sobre as suas preferências e interesses, o programa utiliza uma estrutura de **Árvore de Decisão** para filtrar as opções e sugerir um caminho académico. 

É um projeto excelente para demonstrar o uso de estruturas condicionais e dicionários em Python de uma forma prática e útil.

## ✨ Funcionalidades

- **Interface no Terminal:** Menus em texto limpos e organizados com caracteres Unicode.
- **Navegação Intuitiva:** Sistema de perguntas de escolha múltipla fáceis de responder.
- **Validação de Entradas:** O sistema impede que o programa feche em caso de erro, pedindo ao utilizador para tentar novamente se digitar uma opção inválida.
- **Resultado Direto:** Entrega uma sugestão clara contendo a "Área de Estudo" e o "Curso Sugerido".
